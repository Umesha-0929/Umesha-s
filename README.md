# 🧠 Study Track

**Study Track** is a lightweight web-based task management application designed to help users organize and track their study tasks.

The application provides a simple interface for creating tasks, assigning dates, tracking completion and viewing overall progress.

## ✨ Features

- ➕ Add new study tasks
- 📅 Assign dates to tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Filter tasks by:
  - All
  - Pending
  - Completed
- 💾 Save tasks using browser `localStorage`
- 📊 Visual task completion progress
- 📱 Responsive user interface
- 🎨 Modern glassmorphism-inspired design

## 🛠️ Technologies

- **HTML5**
- **CSS3**
- **JavaScript**
- **Browser Local Storage**

## ⚙️ How It Works

### Add a Task

Enter a task and optionally select a date. Press the **➕** button to add it to the task list.

### Complete a Task

Press the **✔** button to mark a task as completed.

### Delete a Task

Press the **🗑** button to remove a task.

### Filter Tasks

Tasks can be filtered using:

- **All** — Shows all tasks
- **Pending** — Shows unfinished tasks
- **Completed** — Shows completed tasks

### Progress Tracking

The progress bar automatically calculates the percentage of completed tasks.

## 💾 Data Persistence

The application uses the browser's **Local Storage** to save tasks.

This means tasks remain available when the page is refreshed in the same browser.

No server or additional installation is required.

3. Start adding and managing your study tasks.
